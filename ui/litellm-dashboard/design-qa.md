# MoMA 轻量版界面验收清单

本文件提供可复用的检查范围。当前样式以 [DESIGN.md](DESIGN.md) 为准，功能差异、已执行验证及已知限制见 [LITE_UI_CUSTOMIZATIONS.md](LITE_UI_CUSTOMIZATIONS.md#验证记录与限制)。检查项不代表每个提交都已重新验证

## 角色与页面

分别使用管理员和员工身份检查原权限允许的入口、导航和命令搜索。管理员检查首页、模型、密钥、用量、日志、团队、用户、访问组、预算、路由、日志与告警及系统设置，员工检查首页、模型、密钥、用量和团队

直接访问被屏蔽页面、隐藏页签的旧链接及未知地址，核对回退行为。隐藏入口不能被搜索、显示列菜单或旧 URL 参数重新打开，也不能扩大后端访问权限

## 弹窗与条件内容

| 范围         | 重点检查                                                                 |
| ------------ | ------------------------------------------------------------------------ |
| 模型         | 新增与编辑、凭据复用及更新、模式选项、健康状态、重试、员工详情和停用状态 |
| 密钥         | 创建、详情与编辑、有效期、预算、创建成功说明、复制反馈、历史累计花费提示 |
| 用量与日志   | 空状态、筛选下拉、图表刻度与悬停、成功与失败详情、未存储请求数据说明     |
| 用户与团队   | 邀请、批量操作、默认设置、详情、成员角色、扩展字段与空状态               |
| 访问组与预算 | 创建、编辑、详情、模型选择、隐藏资源授权保留和表单校验                   |
| 全局与设置   | 首次命令提示、账户菜单、通知、部署告警、许可证状态、邮件、日志及路由设置 |

条件无法在测试环境触发时，应区分真实浏览器检查、组件回归和源码核对，不能用其中一种替代全部验证

## 文案与数据

中文界面的标题、标签、选项、占位、帮助、反馈与可读名称应使用中文，英文模式保留英文。普通参数标签不追加括号英文名，人民币单位不改变数值或自动换汇。模型标识、用户输入、API 字段、原始请求响应及未知技术错误保持原值

切换语言时检查未提交输入是否保留，筛选与提交仍使用原键和值。系统保留标识仅按完整匹配映射显示名，复制、链接及请求继续使用原始值。条件通知、错误、悬停和无障碍名称都要检查品牌文案

## 布局与交互

按设计规范核对标题与内容边界、字号角色、控件高度、卡片内边距、表格数值对齐、弹窗与表单滚动。检查常用桌面、宽屏和窄桌面，另行声明手机专项是否覆盖。宽表和页签在容器内滚动，避免整页横向溢出，长名称和说明保留查看方式

检查中英文、浅深主题、搜索空状态与恢复、卡片和列表切换、键盘焦点及可读标签。浏览器缩放和长内容不应丢失操作。页面能打开不等于创建、修改、删除、邮件、供应商调用或计费已经验证

## 证据与边界

将具体部署版本、测试账户、截图和执行日志保存在仓库外的私有验收资料中。截图需先检查账号、凭据、请求内容、内部地址和浏览器界面信息，公开分享时只使用专门准备并脱敏的演示数据

发布说明分别记录实际执行的构建、定向测试、浏览器检查、部署健康和业务验证。保留失败与未覆盖范围，不以静态截图、构建成功或少量调用证明跨浏览器、完整可访问性、生产 SSO、计费和持续负载全部通过
