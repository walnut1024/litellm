# MoMA 轻量版界面规范

适用范围为轻量版保留的员工端和管理员端桌面 Web 页面，界面用于日常操作，优先保证紧凑、对齐和扫描效率。保留现有浅蓝灰、白色和蓝紫色品牌体系，以及深色模式、中文和英文。功能、字段、权限、API 和业务数值不随样式调整

## 字号与层级

沿用最小 14px 和相邻 1.5 倍的四档字号，按角色分配，不把普通正文或按钮放大成标题。以下像素值对应默认根字号 16px，实际使用 rem 以支持浏览器缩放

| 角色                                         | 字号    | 行高 | 字重                  |
| -------------------------------------------- | ------- | ---- | --------------------- |
| 正文、说明、导航、按钮、输入、表格、图表标签 | 14px    | 20px | 400，标签和表头 500   |
| 区块标题、弹窗标题、桌面品牌                 | 21px    | 28px | 600                   |
| 页面标题、核心指标                           | 31.5px  | 40px | 650                   |
| 特殊大号展示                                 | 47.25px | 56px | 650，仅确有需要时使用 |

每页保留一个页面标题，工具栏不使用标题字号。页面标题下的说明最多占必要的行数，说明与标题间隔 4px。模型名称、ID 和技术内容不改变原文，长名称换行，长标识在原容器内滚动或省略并保留查看入口。金额和计数使用等宽数字

## 空间与对齐

间距基准为 4px，常用档为 4、8、12、16、20、24px。图标与文字间隔 8px，同一操作组间隔 8px，相关字段间隔 16px，页面区块间隔 16px。不得为同一页面重复添加外层和内层 padding

| 元素         | 规范                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 桌面页头     | 高 56px，左右 20px，品牌和账号垂直居中                                    |
| 桌面侧栏     | 宽 208px，导航文字 14px，行高至少 36px                                    |
| 页面内容     | 桌面左右 20px，上 20px，下 24px，标题、页签和主要内容共享左边界           |
| 页面头       | 标题在左，主要操作在右，包含页签的操作行独占下一行，窄屏自然换行          |
| 卡片与面板   | 内边距 16px，内部区块间隔 12px，圆角 12px，使用一层细边框                 |
| 筛选与工具栏 | 同排控件等高，间隔 8px，允许整组换行，不把文字挤成多行按钮                |
| 表格         | 表头 36px，单元格上下 8px、左右 12px，单行行高至少 36px，多行内容自然增高 |
| 空状态       | 内容自适应，说明居中且紧凑，不靠固定视口高度撑出空白                      |

宽屏使用可用内容宽度，不添加空的占位卡片。图表保留读数需要的高度，排行等可比较的次要内容在宽屏并排，窄屏按原阅读顺序堆叠。数据少时允许真实空白，不补造指标、记录或业务能力

首页使用 12px 区块间距和面板内边距，趋势图高 160px，可用模型卡片将图标和文字横向排列，并平分剩余宽度。默认中文的 1280×720 桌面首屏应展示可用模型及其入口，保持原有字号，长文案与浏览器缩放时仍允许正常滚动

首页和用量概览的花费、请求、Token、平均花费、平均延迟在桌面分为五列，数值共享顶部基线，Token 列稍宽以容纳明细入口。用量排行按行排列，同行面板的顶部对齐。面板内容按组件定义的内边距排布，主题不得再次覆盖导致重复缩进。标记为 numeric 的表格列沿用共享表格的右对齐规则，表头与数值一致

## 控件和表单

桌面普通按钮、输入和单选选择器统一高 32px，按钮水平内边距 12px，图标一般为 16px。分页按钮统一 32px。多选输入和文本域允许随内容增高，不裁掉标签。按钮通过主色、描边和文字区分主次，保持原有禁用、加载、危险和焦点状态

标签与控件间隔 6px，字段间隔 16px，说明使用 14px 和次要文字颜色。弹窗内边距 20px、区块间隔 16px、标题 21px，保留既有最大高度和内部滚动。字段注册、隐藏字段的已有值、校验和提交处理保持原实现

## 响应式与可访问性

1100px 以下继续使用原导航抽屉，600px 以下内容左右间距 12px。手机主要按钮、输入和分页目标至少 40px，导航项至少 44px。页签和宽表在自己的容器内滚动，禁止通过整页横向溢出来容纳内容

颜色复用语义令牌，正文和占位文字在浅深主题中均保持可读对比度。键盘焦点保留，减少动态效果偏好继续由原组件处理，不新增装饰动画。DOM 与视觉阅读顺序保持一致，不移除原可读标签

## 实现与验收

令牌和统一规则在 `src/app/moma-theme.css`，页面骨架复用 `Page` 和 `PageHeader`，图表面板使用 `Primitives`。新增页面优先接入这些组件，不能复制一份局部样式或新增任意字号。页面有不同信息结构时保留必要的展示差异

实际修改范围、社区基线、测试和容器证据记录在 [LITE_UI_CUSTOMIZATIONS.md](LITE_UI_CUSTOMIZATIONS.md)，视觉前后对比记录在 [design-qa.md](design-qa.md)。本轮按桌面 Web 验收，检查保留页面的标题左边界、控件高度、字体角色、卡片内边距、表格密度、表单滚动，以及 1280×720、1536×900 和 900px 窄桌面窗口下的溢出。手机端沿用共享响应式规则，不作为本轮专项设计与验收范围
