# MoMA 轻量版

面向内部团队的模型服务控制台与 API 网关。管理员统一接入模型、配置员工权限和预算，员工查看获授权模型、创建 API 密钥，并通过兼容 OpenAI 的客户端调用

本仓库基于 [LiteLLM](https://github.com/BerriAI/litellm) 定制，`main` 为轻量版维护分支。当前社区源码基线为 `9546f9a69ff470dfcc5a21eccab89d2fd86a634f`，版本为 `1.109.0`。轻量版主要调整控制台的功能入口、中文文案、品牌和布局，模型转发、供应商适配、鉴权及预算计算沿用原有后端实现

## 核心能力

| 能力       | 管理员                                             | 员工                                           |
| ---------- | -------------------------------------------------- | ---------------------------------------------- |
| 工作台     | 查看用量、花费、请求数与可用模型                   | 查看个人用量与可用模型                         |
| 模型广场   | 查看模型目录、能力、价格、调用示例和接入地址       | 查看获授权模型及相同接入信息，使用有效密钥调用 |
| 模型管理   | 接入和维护模型部署、供应商凭据、健康检查及重试配置 | 不开放                                         |
| API 密钥   | 管理密钥归属、模型权限、预算、有效期和状态         | 创建和管理本人有权访问的密钥                   |
| 用量统计   | 按原权限查看全局、用户和团队统计                   | 按原权限查看本人及团队用量                     |
| 团队与用户 | 管理员工、团队、访问组、基本预算及限流             | 查看和操作原权限允许的团队内容                 |
| 请求日志   | 查看请求状态、Token、花费、耗时和请求详情          | 不开放管理员请求日志页面                       |
| 系统设置   | 保留基础路由、日志、告警和控制台设置               | 不开放管理员设置页面                           |

控制台默认中文，支持中英文切换、浅色与深色主题。页面采用统一的紧凑布局，常用表单、抽屉、弹窗、日期和悬停说明按中文界面整理。模型名称、用户输入、API 参数、原始 JSON 和上游错误保留原值

获授权模型无需单独开通，使用具有对应模型权限的 API 密钥即可调用。模型卡片的“立即使用”进入 API 密钥页，不自动创建密钥

## 模型接入

管理员在“模型管理”的“添加模型”中选择供应商。下拉框仅保留现有国产供应商，包含 DeepSeek、阿里云、MiniMax、月之暗面、腾讯云和火山引擎，并默认选中“移动云 MoMA”

模型广场按对外调用的模型组展示目录，保留 OpenAI 协议 Base URL 和 Anthropic 协议 Base URL 及独立复制按钮。模型管理按部署记录维护配置，继续保留轻量版管理范围与中文界面，不恢复此前隐藏的高级页签

移动云 MoMA 使用 OpenAI 兼容协议。管理员填写上游模型名称、实际 API 地址和 API 密钥，使用“测试连接”验证后添加模型。API 地址不预置且必填，模型名称按输入原样提交。各国产供应商继续使用原有适配器和认证字段

供应商目录仅限制新增模型的界面选项，已有模型和凭据保持不变，后端支持范围与 API 权限不受此目录筛选影响

## 轻量版边界

控制台聚焦模型接入、密钥分发、权限预算和用量查询。组织、项目、Playground、Agents、MCP 管理、护栏管理、审计日志及其他非核心入口已从轻量版界面屏蔽，完整范围见[轻量版差异与合并指南](ui/litellm-dashboard/LITE_UI_CUSTOMIZATIONS.md)

管理员保留单点登录与 SCIM 配置入口，以及普通、深色 Logo 和浏览器图标的 URL 设置。未配置自定义 Logo 时使用随镜像打包的移动云官方标志，支持恢复默认。开放配置界面不改变后端鉴权或许可证要求，SCIM 同步接口仍受原企业许可证校验约束

界面屏蔽不等于删除后端能力或关闭 API，授权仍由后端执行。隐藏功能的源码和依赖保留，不承诺镜像体积缩减，也不表示获得企业功能授权

中文界面使用人民币标识，但界面单位不会自动把供应商美元价格换算为人民币。接入时需要正确配置模型费率，页面花费是按配置计算的估算，不能替代供应商账单核对

## 源码与部署

根目录 [Dockerfile](Dockerfile) 从源码构建完整运行时和当前控制台，包含 Python、Rust、Prisma 与前端静态导出

```bash
git clone https://github.com/walnut1024/litellm.git
cd litellm
git checkout main
git pull --ff-only
docker build -t litellm-moma:local .
```

x86_64 服务器可从 [GitHub Release](https://github.com/walnut1024/litellm/releases/tag/moma-lite-v1.0.0) 下载应用与 PostgreSQL 镜像安装包，无需在服务器编译源码，步骤见[安装包说明](docker/lite-release/README.md)

本地部署使用独立 PostgreSQL 数据库，示例 Compose 仅绑定 `127.0.0.1`。将管理员密码、主密钥、加密 salt、数据库密码保存在仓库外的私有环境文件中，供应商凭据通过原生模型管理流程保存。镜像不包含已接入的模型记录或凭据

部署步骤、Compose 镜像覆盖方式、重启和数据保留要求见[本地部署说明](docker/lite-ui-preview.md)。使用根 Dockerfile 构建的镜像时，通过覆盖文件指定镜像，并使用 `--no-build` 启动，避免触发示例 Compose 的 UI 叠加构建流程

示例配置 [lite-ui-preview.yaml](docker/lite-ui-preview.yaml) 的模型列表为空，并按本地测试要求关闭泄露密码校验。该配置用于本地预览，部署到其他环境时需核对密码策略和访问范围。数据库与加密 salt 必须配套保留，日常重启不要删除数据卷
