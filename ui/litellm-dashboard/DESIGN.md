# MoMA 轻量版界面规范

适用范围为轻量版保留的员工端和管理员端桌面 Web 页面，界面用于日常操作，优先保证紧凑、对齐和扫描效率。V4 界面使用浅蓝灰底色、白色面板和蓝色强调色，保留深色模式、中文和英文。功能、字段、权限、API 和业务数值不随样式调整

## 字号与层级

字号使用 rem，以下像素值对应默认根字号 16px

| 角色                             | 字号 | 行高    |
| -------------------------------- | ---- | ------- |
| 辅助说明、分组标签、表头         | 12px | 20px    |
| 正文、导航、按钮、输入、表格内容 | 14px | 20–22px |
| 区块、卡片和普通弹窗标题         | 16px | 24px    |
| 页面标题                         | 24px | 32px    |
| 用量核心指标                     | 28px | 36px    |

每页保留一个页面标题，工具栏不使用标题字号。页面标题下的说明最多占必要的行数，说明与标题间隔 4px。模型名称、ID 和技术内容不改变原文，长名称换行，长标识在原容器内滚动或省略并保留查看入口。金额和计数使用等宽数字

## 空间与对齐

间距基准为 4px，常用档为 4、8、12、16、20、24px。图标与文字间隔 8px，同一操作组间隔 8px，相关字段间隔 16px，常用区块间隔 16px，首页和模型广场使用 20px。不得为同一页面重复添加外层和内层 padding

| 元素         | 规范                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 桌面页头     | 高 48px，左右 20px，品牌和账号垂直居中                                   |
| 桌面侧栏     | 宽 180px，收起时宽 64px，导航行高至少 40px                               |
| 页面内容     | 桌面内边距 24px，内容宽度上限 1920px，标题、页签和主要内容共享左边界     |
| 页面头       | 标题在左，主要操作在右，包含页签的操作行独占下一行，窄屏自然换行         |
| 卡片与面板   | 通用内边距 16px，工作台及广场重点面板 24px，圆角 16px                    |
| 筛选与工具栏 | 同排控件等高，间隔 8px，表格工具栏内边距 16px，允许整组换行              |
| 表格         | 表头 44px，单元格四周 12px，数据行至少 52px，多行内容自然增高            |
| 表格分页     | 表格框内四周留白 12px，框外分页只保留顶部 12px，每页条数与选择器间隔 8px |
| 空状态       | 内容自适应，说明居中且紧凑，不靠固定视口高度撑出空白                     |

宽屏使用可用内容宽度，不添加空的占位卡片。图表保留读数需要的高度，排行等可比较的次要内容在宽屏并排，窄屏按原阅读顺序堆叠。数据少时允许真实空白，不补造指标、记录或业务能力

首页从欢迎横幅进入最近 7 天概览。桌面展示五张指标卡，趋势图高 250px，与使用指引同排。可用模型位于趋势下方，图标和文字横向排列。窄屏允许滚动查看全部内容

模型广场按模型组展示卡片，最小宽度 288px，窄屏不超过容器宽度，首页快捷卡片沿用原尺寸。供应商、模型类型和调用模型 ID 逐行展示，标签左对齐，值右对齐，长值自然换行。调用模型 ID 旁常显复制图标，复制目录接口返回的 `model_group`，不复制后台 UUID 或上游模型名。能力标记与描述使用真实元数据，详情保留上下文、价格及调用示例，不从模型组推断具体部署的暂停状态。管理员模型管理使用部署表格，不提供卡片切换

模型广场顶部最多展示当前目录的前三个授权模型。封面卡片可收起并复用目录详情入口，列表筛选独立作用于下方目录。OpenAI 与 Anthropic 的 Base URL 各有一张接入卡片，桌面双列、窄屏堆叠，各有明确名称、复制按钮和填写说明。OpenAI 地址保留末尾 `/v1`，Anthropic 地址用于 SDK 的 `base_url` 或 `ANTHROPIC_BASE_URL`，不含该后缀。长地址自然换行，不省略复制内容

首页和用量概览的花费、请求、Token、平均花费、平均延迟在桌面分为五列。用量页将筛选集中在同一面板，宽屏导出按钮与页签同排，概览指标与每日用量图表共用面板。用量排行按行排列，同行面板的顶部对齐。面板内容按组件定义的内边距排布，主题不得再次覆盖导致重复缩进。标记为 numeric 的表格列沿用共享表格的右对齐规则，表头与数值一致

## 控件和表单

列表中的实体下钻入口复用 `IdentityCell`，默认名称使用主色并常显右箭头，副标题与 ID 保持次要文字色。悬停时增加浅色强调背景和名称下划线，键盘聚焦时显示内侧 2px 主色边框与名称下划线。只给已有下钻目标的名称应用该样式，静态文本不显示箭头，不把整行改为跳转区域。团队、用户、密钥及其关联实体列使用同一规则，团队内密钥别名也可打开原密钥详情。继续保留原点击回调、真实链接和修饰键打开新标签页的行为

桌面普通按钮、输入和单选选择器统一高 36px，按钮水平内边距 12px，图标一般为 16px。分页按钮统一 36px。多选输入和文本域允许随内容增高，不裁掉标签。按钮通过主色、描边和文字区分主次，保持原有禁用、加载、危险和焦点状态

多选输入与普通输入统一使用 6px 圆角，标签内移除按钮为 20px，避免被通用按钮高度撑大。键盘焦点显示 2px 主题色外框，组合输入在整组获得焦点时显示，保留原有错误边框和禁用状态

标签与控件间隔 6px，字段间隔 16px，说明使用 14px 和次要文字颜色。弹窗内边距 20px、区块间隔 16px、标题 16px，保留既有最大高度和内部滚动。字段注册、隐藏字段的已有值、校验和提交处理保持原实现

管理员配置项使用中文标签，例如“邮件服务器地址”，不追加括号英文参数名。共享 FormField、MountedFormField、自定义表单、表格和设置页遵循同一规则，带提示图标的富文本标签也不追加参数名。必要的大小单位与时区使用中文说明，输入格式中必须使用的字母保留在说明内。参数说明、事件名称、按钮及可读操作名称继续使用现有语言上下文，API、SMTP、TLS 等常用技术名词可保留在正文中。翻译只作用于显示层，不翻译输入值、事件标识、表单键或接口字段。长标签与说明允许自然换行，不降低字号。模型编辑和默认用户设置在桌面采用两列网格，跨行说明不影响下一行字段的起点。错误分析指标统一预留两行标签高度，使数值保持同一基线

## 响应式与可访问性

桌面侧栏收起后保留带可读名称的图标和当前页状态。1100px 以下使用导航抽屉，600px 以下内容左右间距 12px。手机主要按钮、输入和分页目标至少 40px，导航项至少 44px。页签和宽表在自己的容器内滚动，禁止通过整页横向溢出来容纳内容

颜色复用语义令牌，正文和占位文字在浅深主题中均保持可读对比度。键盘焦点保留，减少动态效果偏好继续由原组件处理，不新增装饰动画。DOM 与视觉阅读顺序保持一致，不移除原可读标签

## 实现与验收

令牌和统一规则在 `src/app/moma-theme.css`，页面骨架复用 `Page` 和 `PageHeader`，图表面板使用 `Primitives`。新增页面优先接入这些组件，不能复制一份局部样式或新增任意字号。页面有不同信息结构时保留必要的展示差异

实际修改范围、社区基线与验证限制见 [LITE_UI_CUSTOMIZATIONS.md](LITE_UI_CUSTOMIZATIONS.md)，页面检查范围见 [design-qa.md](design-qa.md)。设计以桌面 Web 为主，验收时核对标题左边界、控件高度、字体角色、卡片内边距、表格密度、表单滚动，以及 1280×720、1536×900 和 900px 窄桌面窗口下的溢出。手机端使用共享响应式规则，实际专项覆盖范围应单独记录
