## 1.5 倍字号阶梯复核

2026-11-01 根据新要求统一字号，方案 2 的布局、配色、图标与操作继续保留，字体尺寸以本节为准

| 档位           | 默认字号 | 实际测量位置                           |
| -------------- | -------- | -------------------------------------- |
| 页面标题       | 40.5px   | 桌面密钥页与用量页标题                 |
| 分区标题与品牌 | 27px     | 桌面品牌、创建弹窗标题、用量指标       |
| 正文与操作     | 18px     | 导航、列表数据、输入框、按钮、表单标签 |
| 辅助信息       | 12px     | 状态标记、表单帮助、紧凑导航与说明     |

四档从 `0.75rem` 逐级乘以 1.5，表中像素值对应浏览器默认 16px 根字号。窄屏使用同一套档位，例如页面标题切换到 27px，不引入新的中间字号。浏览器字体偏好与缩放仍生效

使用真实页面的 computed style 检查管理员和员工密钥页、创建弹窗、用量页和员工模型列表，所检查的可见文字字号均落在四档内。最终创建表单的帮助文字实测为 12px。检查 360px、390px、1100px、1488px 与 1536px，未发现页头溢出，表格保留横向滚动。未提交新密钥，也未修改表单数据
